🎨 Icon Studio

Drag and drop any number of image files here. They stay in the tray until you assign them.
Click an icon to pick it; Ctrl-click to pick several. Picked icons all go to the slot in one go: the first one you pick becomes the slot's icon, and all of them go in the slot's ▾ list so you can swap later.

📁 Icon Registry

Click a slot to make icons for it. Hover and click ▾ to swap between its saved icons. The ▾ by a name lists where the code uses it. Drag one icon onto another to merge them.

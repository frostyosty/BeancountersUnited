🎨 Icon Studio setup

Icon Studio makes icons for the emoji a codebase shows and keeps them in an icon registry. Tell it where this codebase keeps its icons. Nothing is changed until you press Save.

1. The codebase

The folder that holds the project's source. Icon Studio looks through it for a registry, an icons folder and the file types it contains.

2. The icon registry

A JS file that sets a variable to a JSON object of icons, e.g. window.OS_ICON_REGISTRY = {"emoji": {}};. Emoji the studio gives an image are saved in its "emoji" group.
The web root is the folder the registry's image paths are relative to: the folder the pages are served from. The icons folder must be inside it.

3. What to scan for emoji

"Find emoji" reads these folders, in files of these types, and skips comments and logging.

4. Showing the images

A small script that shows the saved image wherever its emoji is text on a page. Leave it unticked if the codebase already swaps emoji for images itself.
